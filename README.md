# Firewall Racer

A simple C game where you drive a car down a 3-lane road and dodge cyber threats (VIR, MAL, PHI). Collect PAT patches to get a shield that blocks one hit.

## Files
- firewall_racer.c: console version (Windows, Visual Studio)
- firewall_racer_raylib.c: graphical version (needs the raylib NuGet package)

## Controls
- A / D (or arrow keys): change lane
- Console version: R = retry, Q = quit
- Graphical version: ENTER = start, R = retry, Q = menu, ESC = exit

## Built with
C, Visual Studio, raylib
